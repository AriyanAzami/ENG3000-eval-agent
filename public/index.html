Group 31 Project Evaluation Agent

ENG 3000 · York University

Describe a proposed engineering project. The agent checks it against professional obligations (Q1), the law (Q2) and benefit to the land (Q3), assesses risk and ethics, and gives a verdict: Proceed, Proceed with Conditions, or Do Not Proceed.

Include in your description

  1. What the project is
  2. Where it is
  3. Engineering disciplines involved
  4. Project phase
  5. Who makes the decisions
  6. Objective
  7. Scope

If any of these are missing, the agent asks for them before it evaluates.
